# OneSIT instructions

Use UK English. Do not use em or en dashes in visible copy. Use clear, direct and concrete language.

Read PRODUCT.md, DESIGN.md and docs/BRAND.md before changing the interface. This is a mobile companion app built with Preact and Vite. Keep the first download small. Do not replace it with a marketing landing page or introduce a server, login, tracking or calendar integration.

The affiliation notice is exactly: Not affiliated with SIT.

Coming-soon services must stay visible in Services with local icons, grey styling and a clear status. They have no live destination or favourite action. Maintain readable label contrast.

Run npm run check. For interaction changes, test the production build in a browser. Keep raw .msg files and private test inputs out of the repository. Use synthetic fixtures in tests.
